# سیستم مدیریت انبار تحت شبکه

این نسخه از برنامه به یک معماری کلاینت-سرور تبدیل شده است که هم بک‌اند (API) و هم فرانت‌اند (رابط کاربری) از یک جا اجرا می‌شوند.

## راه اندازی

۱. **نصب Node.js:** اگر Node.js را روی سیستم خود ندارید، آن را از [nodejs.org](https://nodejs.org/) دانلود و نصب کنید.

۲. **نصب پکیج‌ها:** یک ترمینال یا Command Prompt در پوشه اصلی پروژه باز کنید و دستور زیر را اجرا کنید تا پکیج‌های مورد نیاز سرور نصب شوند:
   ```bash
   npm install
   ```

۳. **اجرای برنامه:** در همان ترمینال، دستور زیر را برای راه اندازی کامل برنامه اجرا کنید:
   ```bash
   npm start
   ```

۴. **دسترسی به برنامه:** مرورگر خود را باز کرده و به آدرس زیر بروید:
   [http://localhost:4000](http://localhost:4000)

   شما باید صفحه ورود به سیستم را مشاهده کنید. سرور باید در تمام مدتی که از برنامه استفاده می‌کنید، در حال اجرا باقی بماند.

## ساختار داده

تمام اطلاعات برنامه (کاربران، قطعات، تراکنش‌ها) در یک فایل پایگاه داده به نام `database.db` در پوشه پروژه ذخیره می‌گردند. این فایل به صورت خودکار توسط سرور ایجاد و مدیریت می‌شود.
